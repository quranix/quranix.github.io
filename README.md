# Quranix | বাংলা কুরআন

বাংলা কুরআন পড়া, শোনা ও আমল ট্র্যাক করার একটি ওয়েব অ্যাপ (PWA)। ফোনে ইনস্টল করা যায় এবং ইন্টারনেট ছাড়াও চলে।

## ফিচার

- কুরআন পড়া: সূরা, পারা, মাক্কী/মাদানী, সংরক্ষিত তালিকা
- বিষয়ভিত্তিক আয়াত ও শব্দার্থ (১৫০ শব্দ)
- শব্দে শব্দে, তাজউইদ, হিফজ মোড
- অডিও তেলাওয়াত ও অফলাইন অডিও
- ৯৯ নাম, হাদিস, দোয়া ও তাসবিহ
- নামাজের সময়, আজান অ্যালার্ট, কিবলা
- হিজরি ক্যালেন্ডার, খতম প্ল্যানার, ট্র্যাকার
- নোট, বুকমার্ক, ইমেজ কার্ড, ব্যাকআপ

## ফোল্ডার গঠন

```
quranix/
├── index.html          মার্কআপ + CSS
├── sw.js               সার্ভিস ওয়ার্কার (অফলাইন), রুটে থাকতে হবে
├── manifest.json       ইনস্টল তথ্য, রুটে থাকতে হবে
├── LICENSE             GNU GPL v3 (অফিসিয়াল টেক্সট, অপরিবর্তিত)
├── NOTICE.md           কপিরাইট, অতিরিক্ত শর্ত, ব্যবহারের অনুরোধ
├── quran-data.js       আরবি + বাংলা অনুবাদ (~৩.৫ MB), এডিটরে খুলবেন না
├── data/
│   ├── topics.js       বিষয়ভিত্তিক আয়াত (QX_TOPICS)
│   ├── dictionary.js   ১৫০ শব্দের অভিধান (QX_DICT150)
│   └── district.js     বিভাগ, জেলা, থানা/উপজেলা
├── js/
│   ├── quran.js        মূল কাঠামো + কুরআন অংশ
│   └── apps.js         নামাজ, তাসবিহ, সেটিংস, হিফজ, তাজউইদ, PWA ইত্যাদি
├── fonts/              ফন্ট ফাইল (fonts/licenses/-এ লাইসেন্স)
└── icons/              অ্যাপ আইকন
```

## কোন ফাইল কখন এডিট করবেন

| ফাইল | এডিট |
|---|---|
| `js/quran.js`, `js/apps.js` | সবসময় |
| `data/dictionary.js` | নতুন শব্দ যোগ করলে |
| `index.html` | মাঝে মাঝে |
| `data/topics.js`, `data/district.js`, `quran-data.js` | সাধারণত না |

## স্ক্রিপ্ট লোড অর্ডার (গুরুত্বপূর্ণ)

`index.html`-এ স্ক্রিপ্ট এই ক্রমে থাকতে হবে, নইলে অ্যাপ চালু হবে না:

```
quran-data.js → data/topics.js → data/dictionary.js → data/district.js → js/quran.js → js/apps.js
```

`js/apps.js` সবার শেষে, কারণ এতে অ্যাপ চালু করার কোড আছে।

## লোকালি চালানো

সার্ভিস ওয়ার্কার `file://` থেকে চলে না, তাই একটা লোকাল সার্ভার লাগবে:

```
python3 -m http.server 8000
```

এরপর ব্রাউজারে `http://localhost:8000` খুলুন।

## নতুন ফাইল যোগ করলে (অফলাইনের জন্য)

1. `sw.js`-এর `ASSETS` লিস্টে নতুন ফাইলের পাথ যোগ করুন।
2. `sw.js`-এ `CACHE` ভার্সন বাড়ান (যেমন `quranix-v23` থেকে `quranix-v24`), যাতে পুরনো ক্যাশ পরিষ্কার হয়।

সতর্কতা: `ASSETS`-এর কোনো পাথ ভুল হলে ইনস্টলে কোনো এরর আসে না, শুধু ওই ফাইল অফলাইনে পাওয়া যায় না।

## অভিধানে নতুন শব্দ যোগ করা (`data/dictionary.js`)

- নতুন শব্দ সবসময় তালিকার **শেষে** যোগ করুন। শব্দের নম্বর (rank) তালিকার অবস্থান থেকে আসে, মাঝে ঢোকালে সব নম্বর সরে যায়।
- নতুন ক্যাটাগরি লাগলে `QX_DICT150_CATS`-এর শেষে যোগ করুন।
- প্রতিটা সারির ৪র্থ ঘর আরবি ধাতু। এটা ডিটেইল পেজ ও সার্চে ব্যবহার হয়, অন্য কিছু বসাবেন না।

## ডেটা, ফন্ট ও লাইসেন্স

- অ্যাপের কোড [GNU GPL v3](LICENSE)-এর আওতায়। কপি বা পরিবর্তন করলে আপনার সংস্করণের সোর্স কোডও একই লাইসেন্সে খোলা রাখতে হবে।
- অতিরিক্ত শর্ত (পরিবর্তিত সংস্করণ চিহ্নিত করা, "Quranix" নাম ব্যবহার না করা) ও ব্যবহারের অনুরোধ [NOTICE.md](NOTICE.md)-এ আছে।
- কুরআনের আরবি টেক্সট ও বাংলা অনুবাদ এই লাইসেন্সের আওতায় **নয়**। ওগুলোর নিজস্ব ব্যবহারের শর্ত প্রযোজ্য:
  - **অফলাইন অনুবাদ:** মুহিউদ্দীন খান, সূত্র [alquran.cloud](https://alquran.cloud)। এটা `quran-data.js`-এ বিল্ট-ইন, ইন্টারনেট ছাড়াই চলে।
  - **অনুবাদ (অনলাইন):** ডঃ আবু বকর মুহাম্মাদ যাকারিয়া, সূত্র [QuranEnc](https://quranenc.com)। ইন্টারনেট থেকে আসে, একবার লোড হলে ডিভাইসে ক্যাশ থাকে। QuranEnc-এর শর্ত মেনে অনুবাদে কোনো বদল ছাড়া সূত্রসহ দেখানো হয়।
- শব্দার্থ ও বিষয়ভিত্তিক আয়াতের ধাতু (Root) ও শব্দের সংখ্যা: [Quranic Arabic Corpus](https://corpus.quran.com) (Morphology v0.4)। এর ব্যবহারের শর্ত corpus.quran.com-এ দেখুন।
- ফন্টগুলোর নিজস্ব লাইসেন্স আছে, `fonts/licenses/` ফোল্ডারে দেখুন।
